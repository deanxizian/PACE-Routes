# PACE Routes

PACE 的已签名、只读路线数据仓库。

本仓库只包含为 PACE 生成的移动端路线目录。PACE 源代码和用户数据始终保留在私有仓库与用户设备中。

- GitHub 主源：https://github.com/deanxizian/PACE-Routes
- Gitee 国内镜像：https://gitee.com/deanxizian/PACE-Routes-Mirror
- `v1/` 下的目录由自动化生成，不接受手工修改。
- 索引使用签名校验，版本化路线文件使用 SHA-256 校验。
- 目录记录保留其数据来源署名与来源链接。

本仓库不存储 PACE 用户的活动、HealthKit 数据、位置请求、照片、视频、备注或任何凭据。

数据权利归各自提供方所有；只有获得相应公开再分发授权的数据才会发布到这里。
